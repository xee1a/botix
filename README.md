# Botix.pl

Strona internetowa Botix: zajęcia z robotyki (LEGO® MINDSTORMS® NXT) dla szkół.

Czysty HTML, CSS i JavaScript, bez kroku budowania. Bez cookies i narzędzi analitycznych.

## Uruchomienie lokalnie

```bash
python -m http.server 5510
```

Potem otwórz http://localhost:5510.

## Struktura

- `index.html`: strona główna (zajęcia, program, pomysły na roboty, cennik, O nas, FAQ, zamówienie)
- `projekty.html`: galeria zdjęć projektów uczniów (instrukcja dodawania zdjęć w komentarzu w pliku)
- `regulamin.html`, `polityka-prywatnosci.html`, `polityka-cookies.html`, `rezygnacja-i-zwroty.html`: dokumenty
- `styles.css`, `script.js`, `assets/`

## Przed publikacją

Elementy oznaczone klasą `todo` (żółte ramki) trzeba uzupełnić prawdziwymi danymi, a potem usunąć z nich klasę `todo`.

LEGO® i MINDSTORMS® są znakami towarowymi Grupy LEGO, która nie sponsoruje, nie autoryzuje ani nie wspiera tej strony.
